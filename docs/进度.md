## 已得到的核心发现

### 关键交互效应

**同一个插补方法，在两类模型上结论完全相反：**

```
xgboost（有原生缺失处理）                glmnet（必须插补）
  L1 原生 NaN     0.95910  ← 最优         L3 约束插补   0.92841  ← 最优
  L2 中位数常数   0.95871                 L2 中位数     0.91775
  L3 条件均值     0.95804
  L4 随机抽真值   0.95618  ← 最差
```

配对检验（同折同行，比看标准差有力得多）：

| 对比 | 差值 | 同号 | t | p |
|---|---|---|---|---|
| L1 − L2 (xgb) | +0.00038 | 4/5 | 3.59 | 0.0231 |
| L2 − L3 (xgb) | +0.00067 | 5/5 | 2.96 | 0.0414 |
| L3 − L4 (xgb) | +0.00186 | 5/5 | 8.49 | 0.0011 |
| L1 − L4 (xgb) | +0.00292 | 5/5 | 26.60 | <0.0001 |
| **L3 − L2 (glmnet)** | **+0.01065** | 5/5 | 69.80 | <0.0001 |

### 机制

**决定因素是插补把缺失行在特征空间里"散开"的程度。**

- L1 把所有未知**聚在一起**，用一个学到的默认分支方向统一处理
- L2 全部填同一个常数，仍然是聚的
- L3 按条件均值散开
- L4 按真实分布随机散开，散得最开

散得越开，需要单独判断的行就越多，出错的机会也越多。glmnet 没有"聚"这个选项，每行都必须用插补值算分，所以猜得准才重要。

> **能把"未知"聚起来处理的模型，聚比猜好；不能聚的模型，猜得准比猜得糙好。**

### 两个被证伪的假设（这是好事，不是失败）

1. **"约束条件插补会提升成绩"** —— 在 xgboost 上它是最差的三条之一（p=0.0020）。
2. **"L3 变差是因为回归估计向均值收缩"** —— L4 用 PMM 完全不收缩，结果更差（p=0.0011）。收缩不是主因。

两次证伪加一次成功的反向预测（"在不能吃 NaN 的模型上我们的方法应该反赢"，实测赢了一个数量级），这条推理链比"我猜对了"有价值得多，而且每一步都有配对检验撑着。

**注意**：约束投影本身实测只在 **0.06%** 的行上触发，L3 目前实质上是链式线性回归插补，"约束"二字名不副实。报告里必须如实说明。
